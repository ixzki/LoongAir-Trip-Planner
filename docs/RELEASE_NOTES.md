## 畅飞行 v1.8.3

### 航线与行程

- 同日往返和跨午夜班次按具体起降时间配对。选定去程后，结果显示可衔接的返程和实际停留时间。
- 查询到航班调时后，往返搜索按当日时刻筛选。已保存行程复查时会核对航班号。
- 兑换截止按北京时间起飞前第 3 天 23:40 计算。次日回流提醒会检查对应航段在提醒时是否仍可兑换。
- 同一航班在不同星期采用不同起降时刻时，逐周校准会分别保存各时刻的执飞日期。

### 同步与提醒

- 首次全网同步按各城市目录和航线日历上次联网成功的时间判断是否复用缓存。目录不完整时保留已有航线，单条航线的不适用日期只影响该方向。
- 更新日历遇到约满、截止等状态时，会清理已过时的余票快照。全网列表、单航线摘要和刷新提示使用同一个 40 天窗口。
- 退出后晚到的登录或续期结果不能覆盖新会话。手工导入须先通过凭据校验，卡片授权标识按脱敏形式显示。
- 重新授予精确闹钟权限后会恢复待触发提醒。导出系统日历时按北京时间选择仍然有效的提醒时刻。

### 安装包

- 正式版文件名为 `ChangfeiXing-v1.8.3-release.apk`，版本码为 20。发布流程会校验签名证书、应用 ID 和版本标签。下载后可用同页的 `SHA256SUMS.txt` 核对文件。
- 日常 CI 提供调试 APK 和供 R8 验证的 `*-release-unsigned.apk`。Android 安装需要已签名的 APK。
