## 畅飞行 v1.8.1

### 核心功能与优化
- **内置全网核验航网**：预置 75 城 / 410 条对称畅飞卡航线与 445 条真实航班时刻；登录查询或同步时自动识别并永久剔除已停航/本卡不适用的失效航线，同时严格区分并保留「仍在范围内 · 近期已全部约满」的有效航线。
- **2026–2027 官方适用窗口校验**：精确纳入 5 段官方适用日期与 125 天屏蔽不可用日期，在月历格、选日器、往返搜索及行程计划中统一标注「不可用」与 3 天内「已截止」。
- **航网地图与列表焕新**：概览模式采用去重后的二次贝塞尔航迹弧线与屏幕碰撞防重叠城市标注；枢纽列表按通航数量降序排列，航线列表优先展示常驻城市出发与到达航线。
- **双主题视觉与通知升级**：全新朱砂无轨迹自适应图标、全屏航迹动画启动页、支持「朱砂 / 薄暮」与深浅色自适应的自定义通知横幅与展开卡片，并精简「行程 / 设置 / 关于」页面结构。

### 安装说明
- 推荐普通用户下载安装 **`ChangfeiXing-v1.8.1-release.apk`**（已启用 R8 混淆与资源压缩，体积约 2 MB）。
- 调试测试可选用 `ChangfeiXing-v1.8.1-debug.apk`。
